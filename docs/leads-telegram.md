# Заявки с сайта → чат в Telegram

Когда кто-то отправляет форму на `/start`, бот пишет в рабочий чат все поля
заявки: номер, имя, компанию, почту, телефон, размер компании, что важно,
запрос цены, время по Москве и страницу. Параллельно заявка уходит письмом
(`docs/leads-email.md`); если одно из мест недоступно, заявка не теряется.

## 1. Бот

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя — например «Кордон — заявки», адрес — например `kordon_leads_bot`.
3. BotFather пришлёт токен вида `1234567890:AA…`. Это пароль от бота:
   не пересылайте его в чаты и письма, сразу переходите к шагу 3.

## 2. Чат

1. Создайте группу, например «Кордон — заявки», и добавьте в неё бота
   и тех, кто отвечает на заявки.
2. Напишите в группе любое сообщение.
3. Откройте в браузере
   `https://api.telegram.org/bot<токен>/getUpdates` — в ответе найдите
   `"chat":{"id":-100…`. Это ID чата, вместе с минусом.
   Если ответ пустой, отправьте в группу ещё одно сообщение и обновите страницу.

Сторонние боты вроде «узнай свой ID» для этого не нужны.

## 3. Переменные окружения на сервере

| Переменная | Значение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | токен из шага 1 |
| `TELEGRAM_CHAT_ID` | ID чата из шага 2, например `-1001234567890` |

После изменения переменных перезапустите сайт. Код читает их только на сервере.

## 4. Проверка

Отправьте тестовую заявку на `/start` — в чате появится сообщение.
Если его нет, в логах сервера будет запись
`[lead] заявка … не ушла в Telegram: …` с причиной:

- `Unauthorized` — неверный токен;
- `chat not found` — неверный ID чата или бота нет в группе;
- `group chat was upgraded to a supergroup` — группа сменила ID,
  повторите шаг 2.3 и обновите `TELEGRAM_CHAT_ID`;
- таймаут — сервер не выпускает соединения к `api.telegram.org`.

## Персональные данные

В сообщении — имя, почта и телефон, а серверы Telegram находятся
за пределами России. Политика на сайте (`/privacy`) об этом не пишет;
решение о трансграничной передаче и уведомлении Роскомнадзора — за юристом.

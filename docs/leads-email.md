# Заявки с сайта → почта

Форма на `/start` отправляет заявку на `/api/lead`. Сервер проверяет её
и отправляет письмо с отдельного ящика-робота на рабочую почту
(по умолчанию `ai@webpractik.ru`). В письме — все поля заявки,
а «Ответить» сразу адресовано клиенту. Параллельно бот пишет в Telegram
(`docs/leads-telegram.md`). Заявка принята, если дошла хотя бы до одного
из двух мест; если ни до одного — форма покажет ошибку.

## 1. Ящик-робот на Mail.ru

1. Заведите отдельный ящик, например `kordon-site@mail.ru`
   (или ящик на домене компании, если домен подключён к почте Mail.ru / VK WorkMail).
   Личный ящик сотрудника не используйте.
2. В настройках ящика: **Безопасность → Пароли для внешних приложений →
   Добавить**, доступ — «Только отправка (SMTP)», если есть такой выбор.
   Это отдельный пароль только для сайта: основной пароль ящика сайт не знает,
   а этот можно отозвать в любой момент.

## 2. Переменные окружения на сервере

| Переменная | Значение |
| --- | --- |
| `SMTP_USER` | адрес ящика-робота, например `kordon-site@mail.ru` |
| `SMTP_PASS` | пароль для внешнего приложения из шага 1.2 |
| `SMTP_HOST` | не обязательно, по умолчанию `smtp.mail.ru` |
| `SMTP_PORT` | не обязательно, по умолчанию `465` (SSL) |
| `LEADS_MAIL_TO` | не обязательно, по умолчанию `ai@webpractik.ru`; можно несколько через запятую |
| `LEADS_MAIL_FROM` | не обязательно, по умолчанию `SMTP_USER`. Mail.ru отправляет только от имени того же ящика |

После изменения переменных перезапустите сайт. Значения никуда больше
не пересылайте: код читает их только на сервере.

Другой почтовый сервис подключается теми же переменными, например
Яндекс 360: `SMTP_HOST=smtp.yandex.ru`, пароль приложения из настроек Яндекс ID.

## 3. Проверка

Отправьте тестовую заявку на `/start`: на `LEADS_MAIL_TO` придёт письмо
«Заявка K-… — Компания, размер», на сайте — пропуск с номером.
Если письма нет, в логах сервера будет запись
`[lead] заявка … не ушла в почту: …` с причиной:

- `Invalid login` — неверный адрес или пароль приложения;
- `Sender address rejected` — `LEADS_MAIL_FROM` не совпадает с ящиком-роботом;
- таймаут — сервер не выпускает исходящие соединения на порт 465.

Если письмо пришло в спам — отметьте «Не спам» и добавьте адрес робота
в контакты получателя.

# Кордон AI — сайт

Сайт корпоративного ИИ-шлюза «Кордон AI»: шлюз ставится в контур компании, маскирует персданные и ключи,
выбирает модель (внешнюю или локальную), ведёт лимиты, отзывает доступ и пишет журнал в SIEM.
Аудитория — ИТ-директор и DevOps, служба ИБ, финансовый директор.

## Стек

- Next.js 16 (App Router, Turbopack), React 19 с React Compiler, TypeScript
- CSS Modules, токены — в `src/app/globals.css`, шрифты — в `src/app/fonts.ts`
- GSAP — анимации сцен, Lenis — плавная прокрутка
- three.js — только объёмная сцена первого экрана

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

```bash
npm run build   # продакшен-сборка
npm start       # запуск собранного сайта
npm run lint    # ESLint (правила Next и React Compiler)
```

## Оформление

- Палитра: чернильный `#0b1324`, кобальт `#2a47d6` (кнопки, активные элементы, запросы внутри контура),
  золото `#e0b04a` — только ядро Кордона, метки маскирования и экономия; красный — утечки и «стоп»,
  зелёный — «разрешено».
- Шрифты: Wix Madefor Display (заголовки, крупные числа) и Wix Madefor Text (текст и интерфейс; у цифр в данных —
  `font-variant-numeric: tabular-nums`). Моноширинного шрифта нет.
- Каждый блок (заголовок и сцена) целиком помещается в окно: 24″ при 100 % (~1920×920) и ноутбук (~1440×800).
  Отступы и размеры привязаны к высоте окна (`vh`), заголовки — в одну строку, пока хватает ширины.
- Типографика строк (тире не в начале строки, короткие предлоги не висят) — `src/lib/typo.ts`.

## Страницы

| Адрес | Что на странице | Компоненты |
| --- | --- | --- |
| `/` | первый экран (3D «Периметр» или видео), два равных блока «Защита» и «Окупает себя» по три сцены, решения по ролям, кто делает, следующий шаг | `hero`, `home`, `problem`, `inside`, `rules`, `economics`, `blocks` |
| `/product` | замена двух строк в коде, шесть проверок на запросе, модули, способы подключения и модели, схема развёртывания, обучение агентов | `product` |
| `/security` | пять рубежей, цифры из исследований, маскирование в три окна, классы данных и политика, атаки, как меряем защиту | `security` |
| `/solutions` | три роли | `home/RoleCards` |
| `/solutions/it` | «было/стало» для ключей, виртуальные ключи, три ситуации, периметр агентов, развёртывание | `it` |
| `/solutions/infosec` | лента журнала, расследование одним поиском, правила, требования регулятора | `infosec`, `rules` |
| `/solutions/finance` | чеки → один счёт, калькулятор, маршрут по цене, лимиты, отчёт | `finance`, `economics`, `blocks` |
| `/pricing` | кого считаем, конфигуратор лицензии, база и модули, рост лицензии за три года, услуги, вопросы | `pricing` |
| `/start` | три шага, заявка на разбор и стенд, вопросы | `start`, `app/api/lead` |
| `/about` | цифры, руководители и их каналы, канал «Корпоративный ИИ без воды», Talent Mind | `about` |

Общие части: шапка и подвал (`components/Nav.tsx`, `Footer.tsx`, карта сайта — `lib/site.ts`), шапка страницы,
блок, вопросы и последний блок (`components/site`). Сцены сами листают шаги, пока видны на экране, и встают
на паузу под курсором и в фокусе (`lib/useCycle.ts`). При «уменьшить движение» показываются итоговые кадры.

## Что нужно решить до публикации

- **Куда уходит заявка.** `src/app/api/lead/route.ts` проверяет данные и пишет в лог только номер заявки,
  размер компании, приоритеты и выбранную лицензию — доставку (почта, Telegram или CRM) нужно подключить.
- **Политика обработки ПДн.** `src/app/privacy/page.tsx` — заглушка, нужен текст от юристов.
- **Видео первого экрана.** Когда будет ролик, укажите его в `src/lib/media.ts` — он заменит 3D-сцену.
- **Состав базы и модулей.** Список на `/pricing` (`components/pricing/Included.tsx`) — сверить с тарифами.
- **Требования.** 152-ФЗ и пункты приказа ФСТЭК № 117 (`components/infosec/Compliance.tsx`) — согласовать
  формулировки с юристами.
- **Бенчмарки.** На `/security` показано, как считается каждая метрика; цифр нет — их даёт прогон на стенде.
- **Примеры.** Запросы сотрудников, события журнала, ключи, расходы команд — иллюстрации. Экономика — пример
  с допущениями, которые меняет посетитель (`components/economics/calc.ts`).
